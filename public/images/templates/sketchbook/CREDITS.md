# Asset credits — Sketchbook template

The following files in this directory are sourced from the **ThreeUI Community**
project (`MengTo/threeui` on GitHub, published as `@designcodeio/threeui` on npm),
MIT licensed:

- `bg-wash.jpg` — watercolor paper wash background texture
- `botany-left.png`, `botany-right.png` — botanical corner illustrations
- `bloom.png` — botanical accent illustration
- `divider.png` — decorative section rule

Source: https://github.com/MengTo/threeui (Community/open-source tier — MIT license
for application code and Community imagery, per the repository's own README and
`ASSET-LICENSES.md`). Fetched 2026-09-12.

Not used: the nine hand-drawn Singapore landmark illustrations from the original
"Meng To Sketchbook" landing page (Marina Bay Sands, Merlion, etc.) — those are
tied to a specific person's personal sketchbook/portfolio content and are replaced
here with each couple's own real photos, per this template's purpose as a wedding
invitation gallery.

Fonts (Instrument Serif, Newsreader) are loaded from Google Fonts at runtime
(both are freely licensed there under the SIL Open Font License) rather than
self-hosting the woff2 files, to stay consistent with how every other template
in this project loads fonts.
