## 2. Overview

**Japanese Ryokan** adalah template undangan premium dengan vibe *zen minimalism* — terinspirasi dari ryokan tradisional Jepang (penginapan klasik), seni *sumi-e* (lukisan tinta hitam), kertas *washi*, dan musim sakura di Kyoto. Filosofi desainnya adalah *kanso* (簡素 — simplicity) dan *yugen* (幽玄 — depth in subtlety): warna lembut, *whitespace* generous, animasi yang menenangkan, bukan ramai.

### Target Audience

- Pasangan dengan estetika **clean-minimalist** (penggemar MUJI, Aman, Kinfolk)
- Penggemar **J-culture / J-pop / anime / J-drama** yang ingin sentuhan kultural Jepang halus
- Pasangan yang menikah di **musim semi** atau punya tema *sakura* / *cherry blossom*
- Pasangan yang ingin alternatif dari template floral berbunga ramai — sesuatu yang elegan tapi *understated*

### Design Pitch

> "Sebuah undangan yang membuka seperti tirai *noren* sebuah ryokan di Kyoto: tenang, hangat, penuh hormat. Setiap *section* diawali sapuan kuas *sumi-e* organik, ditemani kelopak sakura yang melayang lembut. Tidak ada kebisingan visual — hanya *indigo*, *washi cream*, dan *sakura pink* yang berbicara pelan."

## 4. User Flow

```
noren (curtain reveal)  →  cover (full-bleed cover photo)  →  content (sections)
```

- **Phase 0 — `noren`**: Layar penuh *washi cream*. Tirai *noren* indigo tergantung dari atas, terbelah di tengah, ada kanji *kamon*. CTA: "ようこそ Welcome".
- **Phase 1 — `cover`**: Cover photo full-bleed + *sumi-stroke* di bawah nama + *tategaki* tanggal vertikal di kanan.
- **Phase 2 — `content`**: Semua *section* dari catalog, masing-masing diawali *sumi-stroke header* + opsional *tategaki* secondary header.

Phase state dikelola via `phase` ref di `JapaneseRyokanTemplate.vue`, default `'noren'`. Transition: `<Transition name="ryokan-phase" mode="out-in">`.

#### Japanese font fallback strategy

- **Preload `Noto Sans JP`** weight 400 + 700 via `<link rel="preload" as="font">` di `app.blade.php` head — kanji harus tampil tanpa *FOUT* (Flash of Unstyled Text).
- Untuk *latin-only* user (browser tanpa font Jepang ter-install), Google Fonts subset `&subset=japanese` di URL.
- **Fallback stack** untuk title: `'Shippori Mincho B1', 'Noto Serif JP', 'Cormorant Garamond', Georgia, serif`.
- Kalau `ryokan_kanji_headers = false`, font Jepang TETAP di-load (karena bisa muncul di *noren kanji*) — tapi *swap* lebih cepat: `font-display: swap`.

```html
<!-- app.blade.php head -->
<link rel="preload" as="font" type="font/woff2"
      href="https://fonts.gstatic.com/.../NotoSansJP-Regular.woff2" crossorigin>
<link rel="stylesheet"
      href="https://fonts.googleapis.com/css2?family=Shippori+Mincho+B1:wght@400;700&family=Noto+Sans+JP:wght@400;700&family=Cormorant+Garamond:wght@400;600&family=Sawarabi+Mincho&display=swap">
```

## 7. Phase Details

### Phase 0 — `noren` (`RyokanNoren.vue`)

**Purpose:** Pintu masuk seremonial — meniru tirai *noren* di pintu masuk ryokan.

| Aspek | Detail |
|---|---|
| Background | Full-screen `#f3ede4` (washi-cream) dengan `washi-grain.svg` overlay (opacity 0.4) |
| Element utama | 2 *noren panels* (`noren-left.png` + `noren-right.png`) tergantung dari atas, posisi center, total width 400px |
| Kanji centerpiece | Kanji konfigurable (`ryokan_noren_kanji`, default `寿`) di tengah pertemuan dua panel — font `Shippori Mincho B1` 64px, warna emas `#8c6b3f` |
| Alternative | Kalau user upload custom *kamon*, tampilkan `kamon-generic.svg` di atas kanji |
| Sub-text | "ようこそ" 18px `Sawarabi Mincho` di atas, "Welcome" 14px letter-spacing 4px `Cormorant Garamond` di bawah |
| Couple line | "`{groomNick}` & `{brideNick}`" — 24px serif, muted |
| CTA | Button "Buka Undangan" — `indigo` text, no bg, border-bottom 1px sumi-stroke SVG sebagai underline, hover: stroke draws |
| Tap behavior | Tap CTA atau tap noren → trigger `phase = 'cover'` via animasi noren-part |

**Layout:**

```

│                                │
│        ようこそ                │
│        Welcome                 │
│   ╔══════════╦══════════╗      │

│   ║    寿    ║   (kanji │      │
│   ║          ║   center)│      │
│   ╚══════════╩══════════╝      │
│                                │
│      {groom} & {bride}         │
│                                │

│                                │
└────────────────────────────────┘
```

### Phase 1 — `cover` (`RyokanCover.vue`)

| Aspek | Detail |

## 8. Content Sections

Setiap section pakai `<RyokanSectionHeader>` yang punya:
- Sumi-stroke SVG underline (variant 1-5, di-rotate berdasar index)
- Title (Cormorant Garamond SC, 28px, tracking 4px, uppercase)
- Optional *tategaki* secondary header (kanji dari `ryokan_kanji_dict[sectionKey]`)
- Generous padding atas/bawah

> **Rule:** semua section pakai key dari [Section Catalog](../2026-05-17-ai-new-template-guide-design.md#32-section-catalog). JANGAN invent section baru.

### Sumber & Originality

- **Sumi brush vectors**: free CC0 sources — Freepik (filter free + attribution), [unblast.com](https://unblast.com), [svgrepo.com](https://www.svgrepo.com/collection/japanese-ink-strokes). **AI MUST**: kalau ambil dari Freepik, simplify ulang di Figma/Inkscape supaya **original** (jangan langsung pakai SVG yang ada watermark / copyright).
- **Sakura SVG**: CC0 dari svgrepo, atau hand-draft 5-petal shape simple di Figma (1 jam max).
- **Noren PNG**: render dari Figma sendiri — rectangle indigo + fabric noise filter + transparent fade di edge dalam.
- **Washi texture**: generate via Figma noise/grain filter, atau pakai CC0 texture dari [Texture.Ninja](https://texture.ninja).
- **Kamon SVG**: draft sendiri — generic crane (tsuru) atau cherry blossom — JANGAN pakai *mon* keluarga nyata (copyright/kultural sensitif).
- **Fuji silhouette**: single bezier path, < 1KB SVG.

**Originality requirement**: tidak boleh ada aset yang punya watermark, tidak boleh re-distribute aset berbayar. Kalau ragu, **draft sendiri** — semua aset di atas bisa dibuat ulang dalam < 4 jam total.

## 10. Animation Spec

Semua animasi WAJIB punya `@media (prefers-reduced-motion: reduce)` fallback — kritis untuk sakura petals.

### 10.1 Noren part (phase 0 → 1)

```css
.ryokan-noren-left  { transition: transform 1.4s cubic-bezier(0.65, 0, 0.35, 1); }
.ryokan-noren-right { transition: transform 1.4s cubic-bezier(0.65, 0, 0.35, 1); }

.ryokan-noren.parting .ryokan-noren-left  {
    transform: translateX(-110%) skewX(-2deg);
}
.ryokan-noren.parting .ryokan-noren-right {
    transform: translateX( 110%) skewX( 2deg);
}
```

- Timing: 1.4s, easing cubic-bezier(0.65, 0, 0.35, 1) — soft cloth feel
- Skew subtle untuk simulasi kain berkibar
- On `transitionend` → emit `phase = 'cover'`

### 10.2 Sumi brush stroke draw

```css
.ryokan-sumi-path {
    stroke-dasharray: 600;
    stroke-dashoffset: 600;
    animation: ryokan-sumi-draw 1.8s cubic-bezier(0.45, 0.1, 0.25, 1) forwards;
}
@keyframes ryokan-sumi-draw {
    to { stroke-dashoffset: 0; }
}
```

- Easing custom — irregular untuk organic brush feel (bukan linear)
- Trigger: on mount untuk cover, on intersection untuk section header (lewat `vReveal`)
- Stroke-linecap: round, stroke-linejoin: round

### 10.3 Sakura petal fall (ambient)

```css
.ryokan-petal {
    position: fixed;
    top: -40px;
    pointer-events: none;
    animation:
        ryokan-petal-fall  14s ease-in-out infinite,
        ryokan-petal-sway   4s ease-in-out infinite alternate,
        ryokan-petal-spin   8s linear        infinite;
}
@keyframes ryokan-petal-fall {
    0%   { transform: translateY(-40px); }
    100% { transform: translateY(100vh); }
}
@keyframes ryokan-petal-sway {
    0%   { margin-left: -25px; }
    100% { margin-left:  25px; }
}
@keyframes ryokan-petal-spin {
    0%   { rotate: 0deg; }
    100% { rotate: 540deg; }
}
```

- Count: 5-8 (configurable via `ryokan_petal_count`)
- Staggered `animation-delay`: 0s, 1.8s, 3.5s, 5.2s, 7s, 8.5s, 10s, 12s
- Different `left` position untuk tiap petal (10%, 25%, 40%, 55%, 70%, 85%)
- `z-index: 1`, `pointer-events: none` — TIDAK boleh block touch/click
- Petal SVG varies per index (cycle 1-5)

### 10.4 Washi grain shimmer

```css
.ryokan-washi-bg {
    background-image: url('/images/templates/japanese-ryokan/washi.webp');
    background-size: 512px 512px;
    animation: ryokan-washi-shimmer 12s linear infinite;
}
@keyframes ryokan-washi-shimmer {
    0%   { background-position:    0px    0px; }
    100% { background-position: -512px -512px; }
}
```

- Very subtle, hampir tidak terlihat (tileable shift)
- Linear easing untuk continuous feel

### 10.5 Section reveal (`vReveal` + `.ryokan-reveal`)

```css
.ryokan-reveal {
    opacity: 0;
    transform: translateY(24px);
    transition: opacity 1s ease, transform 1s ease;
}
.ryokan-reveal.ryokan-visible {
    opacity: 1;
    transform: none;
}
```

- Lebih lambat dari Netflix (1s vs 0.7s) — untuk zen feel
- Translate kecil (24px) — restrained motion

### 10.6 Tategaki text reveal

```css
.ryokan-tategaki {
    writing-mode: vertical-rl;
    text-orientation: upright;
    clip-path: inset(0 0 100% 0);
    transition: clip-path 1.5s cubic-bezier(0.65, 0, 0.35, 1);
}
.ryokan-tategaki.is-revealed {
    clip-path: inset(0 0 0 0);
}
```

- Clip-path reveal top → bottom (simulasi kuas menulis dari atas)
- Triggered via `vReveal`

### 10.7 Kanji fade-in stagger (per character)

```css
.ryokan-kanji-char {
    opacity: 0;
    animation: ryokan-kanji-in 0.6s ease forwards;
    animation-delay: calc(var(--i, 0) * 0.15s);
}
@keyframes ryokan-kanji-in {
    to { opacity: 1; }
}
```

```vue
<span v-for="(c, i) in chars" :key="i"
      class="ryokan-kanji-char" :style="{ '--i': i }">{{ c }}</span>
```

- Per-char delay 0.15s
- Untuk noren kanji + tategaki secondary headers

### 10.8 Photo gallery hover

```css
.ryokan-gallery-item img {
    transition: transform 0.4s ease-out;
}
.ryokan-gallery-item:hover img {
    transform: scale(1.03);
}
.ryokan-gallery-item:hover .ryokan-grain-overlay {
    opacity: 0.1;  /* dari default 0.25 */
}
```

### 10.9 Reduced-motion guard (MANDATORY)

```css
@media (prefers-reduced-motion: reduce) {
    .ryokan-reveal { opacity: 1; transform: none; transition: none; }
    .ryokan-noren-left,
    .ryokan-noren-right { transition: none; }
    .ryokan-sumi-path { stroke-dashoffset: 0; animation: none; }
    .ryokan-petal { display: none; }  /* CRITICAL — petals stop entirely */
    .ryokan-washi-bg { animation: none; }
    .ryokan-tategaki { clip-path: none; transition: none; }
    .ryokan-kanji-char { opacity: 1; animation: none; }
    .ryokan-phase-enter-active,
    .ryokan-phase-leave-active { transition: none; }
}
```

> **CRITICAL**: `.ryokan-petal { display: none }` — bukan sekedar pause. User reduced-motion harus benar-benar tidak melihat petals jatuh (motion-sickness trigger).

const props = defineProps({ invitation: Object })

const {
    // theme
    primary, primaryLight, bgColor, accent, fontTitle, fontHeading, fontBody,
    // data
    groomNick, brideNick, groomName, brideName,

    // section
    sectionEnabled, sectionData, sectionBg, bgStyle,
    // gate
    gateOpen, contentOpen, triggerGate,
    // music
    audioEl, musicPlaying, toggleMusic,
    // forms
    rsvpForm, rsvpSubmitting, rsvpSuccess, submitRsvp,
    msgForm, msgSubmitting, msgSuccess, submitMessage, localMessages,

    galleryLayout: 'grid',

## 15. Anti-Halu Notes (Template-Specific)

| Risk | Rule |
|---|---|
| Invent kanji custom | **JANGAN** auto-generate kanji untuk section yang user tidak set di `ryokan_kanji_dict`. Pakai default dari Section 11 atau hide kanji header kalau dict key tidak ada |
| Use copyrighted *mon* | **JANGAN** pakai kamon keluarga Jepang nyata (Tokugawa mon, dll). Pakai `kamon-generic.svg` (crane/sakura generic) |
| Mistranslate honorific | **JANGAN** auto-tambah `-san`, `-sama` ke nama tamu. User input nama as-is |
| Invent vertical date format | **JANGAN** auto-convert "17 Mei 2026" ke "二〇二六年五月十七日" tanpa user explicit opt-in. Default: pakai format Latin yang user input, kecuali user toggle "Use Japanese date format" |
| Section custom | **JANGAN** bikin section "tea ceremony", "kimono showcase" — pakai ONLY key di [Section Catalog](../2026-05-17-ai-new-template-guide-design.md#32-section-catalog) |
| Re-implement countdown | **JANGAN** bikin custom countdown logic — pakai `countdown` + `pad` dari composable |
| Petal count > 8 | **JANGAN** allow user input > 8 (performance + accessibility) — clamp di component |
| Bypass composable for forms | **JANGAN** bikin custom RSVP submit handler — pakai `submitRsvp` + `submitMessage` dari composable |
| Hardcode color | **JANGAN** hardcode `#1c2e4a` di template. Pakai `primary` ref dari composable (user bisa override) |
| Animate `width`/`height`/`top`/`left` | **JANGAN** — pakai `transform` + `opacity` (lihat AI guide rule) |
| Forget reduced-motion for petals | **CRITICAL** — `.ryokan-petal { display: none }` di reduced-motion query |
| Block touch via petals | **CRITICAL** — `pointer-events: none` wajib di `.ryokan-petals` container |
| Skip JP font preload | **JANGAN** lupa preload `Noto Sans JP` — FOUT pada kanji sangat jelek |
